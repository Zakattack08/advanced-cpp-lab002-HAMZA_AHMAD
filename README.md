# Lab 002: C++ Basics and Practice Exercises

This assignment gives students a set of beginner-level C++ exercises.
The goal is to practice loops, conditionals, arrays, strings, functions, and basic problem solving.

## Exercises Included

1. Sum values from 1 to 100
2. Factorial
3. Check if a number is even
4. Find the maximum value in an array
5. Find the minimum value in an array
6. Compute the average of an array
7. Sum the digits of a number
8. Reverse a string
9. Count vowels in a string
10. Check if a number is prime
11. Compute power(base, exponent)
12. Compute the Fibonacci number

## GitHub Classroom Instructions

- Read the TODO comments in the source files.
- Implement the functions in src/exercise.cpp.
- Update the main program in src/main.cpp to demonstrate your work.
- Run `make test` to check your solutions.
- Submit your code when the assignments are complete.

## Build Instructions

1. Clone the repository
2. Navigate to the project directory
3. Run `make`
4. Run `make run`
5. Run `make test`
6. Run `make clean` when finished
